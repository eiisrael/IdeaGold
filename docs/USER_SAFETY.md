# Segurança do usuário

- Use somente endereço público XMR.
- Nunca informe seed phrase, private spend key ou senha da carteira.
- Mineração é visível, iniciada e interrompida pelo usuário.
- IdeaGold não desativa antivírus, não instala persistência furtiva e não minera em máquinas sem autorização.
- Elevação de Administrador no Windows é solicitada explicitamente apenas para recursos como Huge Pages/MSR quando necessários.
