# QA Scope

Automated QA cobre sintaxe/importações, matemática, estatística, otimização, scoring, segurança e serialização que podem ser validados sem hardware.

Hardware QA exige execução local para validar Huge Pages/MSR, sensores, energia medida, OpenCL/GPU quando habilitado, latência/pool e hashrate real. Esses dados nunca são falsificados no runner de CI.
