Como conectar uma máquina

Deixe a HTTP API do XMRig em 127.0.0.1. O agente lê localmente e envia só métricas assinadas ao painel.
IDEAGOLD_SERVER=https://SEU-PAINEL WORKER_SHARED_SECRET=SEU_SEGREDO WORKER_ID=rig-01 WORKER_NAME=VPS-01 XMRIG_API=http://127.0.0.1:18080/2/summary node worker-agent.js

Por que isso é “cloud” de verdade?

Você pode instalar o agente em máquinas físicas, VPS ou instâncias cloud em que mineração seja expressamente permitida. O painel agrega tudo em uma malha única sem fornecer shell remoto, persistência escondida ou download silencioso de mineradores.

2. Segredo GoldMesh

node -e "console.log(require('crypto').randomBytes(32).toString('hex'))"
Use o mesmo segredo no painel e nos workers.
